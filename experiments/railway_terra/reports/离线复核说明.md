## 操作

解压到 Windows 较短目录，在解压后的 `ATLAS_TERRA_SUPPLEMENT` 根目录打开 PowerShell，首先核对清单：

```powershell
& .\delivery\runtime\python\python.exe -I -B .\continuation3\delivery\verify_package.py
```

此命令重算四段各自源码/计划及运行文件的八套证据清单、Python 运行时及当前包清单的 SHA-256。`pass: true` 表示所列文件一致，不替代模型评分重验。

随后对实际最终 XMI、响应、预算及配对统计进行独立核验：

```powershell
& .\delivery\runtime\python\python.exe -I -B .\review\continuation3\verify_final.py --output .\review\continuation3\editor_check
```

输出目录必须不存在；再次执行使用另一个新目录名。审查器禁止 Python 网络访问，不导入付费 provider、不访问 API 配置，不重新序列化原始 XMI；Java 默认读取包内副本。生成的原生回执和报告写在新目录，封存实验文件保持不变。应分别核对 `evidence_integrity=PASS`、`study_completion=COMPLETE`、原生评分零差异及 72 个已知终点。包内正式审查报告路径由本目录的 `最终独立审计.json` 与 `审计报告索引.json` 明确给出。

如需重算计数及 CSV：

```powershell
& .\delivery\runtime\python\python.exe -I -B .\continuation3\delivery\summarize_current.py
```

此命令只重新导出当前三个派生文件，不改变原实验；建议先完成清单核验。派生文件若因编辑发生字节差异，清单应据实报告。
