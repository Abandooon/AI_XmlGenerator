| Repository entry | Contents |
| --- | --- |

Start with [the response matrix](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/REVIEW_RESPONSE_MATRIX.md), then follow [the current English manuscript index](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/current/english/LOCATIONS.md), [the data crosscheck](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/PAPER_DATA_CROSSCHECK.md) and [the command list](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/COMMANDS.md). [The release manifest](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/RELEASE_MANIFEST.json) identifies all delivered files. [The execution audit](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/validation/publication_review/COMMAND_AUDIT.md) records the commands actually tested for this revision.

A GitHub archive contains a single enclosing directory. Enter that directory before using the root commands. Keep all experiment archives, manifests and the four Terra archive parts together. Newly generated outputs must be placed outside the release tree. The commands do not access model APIs.

The old reviewer link to `Abandooon/ATLAS/blob/main/nlp_require/complex.json` is not the current 20-case corpus. [The requirement source guide](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/sources/AUTOSAR_REQUIREMENT_PROVENANCE_AND_DESIGN.md) identifies the current cases and their provenance.

The supplied manuscript is English. Earlier Chinese drafts and immutable source notes are retained for provenance; current review links lead to the English source and PDF.
