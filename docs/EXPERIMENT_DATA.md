# Experiment data

This index links independently aggregated metrics to the retained records and the code used to check them. The command reads experiment artifacts and makes no model requests.

Run from the repository root.

```text
python -B inspection/check_experiment_data.py
```

The default output is JSON on standard output. Use `--output` with a path outside the repository to save a report. `--format markdown` selects this navigation format. The command rejects output paths within the repository.

## Evidence and units

AUTOSAR artifact counts are checked against the original archived files; recorded token usage is summed from retained provider records. Railway and second-LLM costs are summed from original response files. PIL decisions, repair inputs, and endpoint scores are reconstructed from the raw answer ledger. Paired intervals are recalculated from the recorded units.

The 1,085 constraint records are counted in the published JSON. The 6,533 constraint associations, 11,177 nodes, and 14,106 relationships are retained Neo4j context counts; this command does not rebuild that graph. Configured validation-rule counts are separate from the checks executed for a particular task.

Decoding interventions are recounted from retained `binding_step` flags. This command does not regenerate historical logits or masks. Native XSD/EMF/VIATRA checks are exercised by the dedicated release verifier.

A selector names fields or an archive member inside its linked source. Denominators are recorded explicitly for proportions. Unrounded values are retained in JSON; this navigation displays at most eight significant digits for noninteger values.
