# 方法、数据与材料自审

现有证据支持限定范围内的 ATLAS 方法和当前中文章节。本轮未发现需要改写主要结果或重跑实验的问题，修正的是输入披露、推论边界和发布说明。复核以保存的源码、原始制品、逐单元结果和专家记录为依据；独立复核程序不等于外部第三方专家认证。

1. **AUTOSAR 输入披露。** 英文需求之外，案例结构化规格和既有接口目录提供精确对象、引用及数值；确定性适配器完成绑定。同一案例规格也供原任务验收使用。正文和附录 A.2 已补清，避免将整体流程通过率误写为独立自然语言提取能力。
2. **跨模型修复解释。** Luna 与 Terra 的初始失败集合不同；条件恢复比例不能分离模型修复能力。Terra 的 GS/GF 均为 22/24，各有一个独有成功，不支持 GF 的新增成功优势或两策略等效。附录 D.4 已明确。
3. **方法责任边界。** 方法论保持已有或外部显式元模型、元模型锚定的 ICM 构建、可实现的生成约束和生成后检查。自定义验证器为 LLM 辅助人工编写；未自动构建任意元模型或形式化验证程序。本轮无需再改方法正文。
4. **实验命名。** 旧发布说明中的铁路 T 已改为任务义务故障注入；AUTOSAR 动态托管流程与本地 vLLM 解码机制实验继续分开解释。论文不以最终 schema 候选数量作为中心叙事。
5. **数据完整性。** 原四项实验记录保留；补充实验的全部 24 任务、失败、未知用量和预算记录一起纳入。原封存 ZIP 按字节无损分块，保留原 SHA-256；可浏览源码是包内文件的精确副本。
