            生成规则:
            顶层结构、键名、嵌套层级必须严格匹配上述接口 JSON Schema。
            每个接口条目的 SHORT-NAME = Round1 interface_plan[].name。
            键名一律使用 AUTOSAR XML 标签（不要使用驼峰别名）。
            所有 *REF 字段必须是对象，包含 @DEST(引向的实例类型) 与 #text(引向的实例路径)。
            仅使用 Schema 中出现的字段；不要新增未定义字段。
