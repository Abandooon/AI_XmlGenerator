# Response to the editor and reviewers

This English matrix retains all 31 normalized comment identifiers from the previous response matrix. The concern summaries are paraphrases, not quotations or newly attributed reviewer statements. The [decision letter](sources/SOSYM-26-00005681_DECISION_LETTER_2026-06-18.txt) remains the source for the original comments.

The responses refer to the current revision: [manuscript](current/manuscript.md), [Word manuscript](current/manuscript.docx), [appendix](current/appendix.md), and [Word appendix](current/appendix.docx). This matrix documents the substantive changes and their evidence; it does not state that an English submission has been completed. Section, figure and table references follow the current manuscript structure. Page and line references will be added after final typesetting.

Section 3 presents the method; Sections 4.2, 4.3, 4.4 and 4.5 report AUTOSAR, the local AUTOSAR–vLLM study, railway models and private international law (PIL), respectively; Section 4.6 discusses validity. Appendices A–D follow that same experimental order. Principal comparisons and the minimum statistical specifications remain in Appendices C.2 and D.2. Detailed resampling, sensitivity analyses and corrected tests are maintained in the repository's [statistical analysis][S], rather than a separate statistical submission document.
