# ATLAS 中文图与统一图形规范

图1至图5已嵌入当前方法论章节，图注同步更新。此目录为当前中文图的统一来源，保留可编辑 SVG、PNG 及矢量 PDF，供作者后续手动重绘。

参考用户指定的 `E:\博士材料\ATLAS论文\论文图\prism-overview-arch.pdf` 底部图例，保留实线数据流、虚线控制流的区分。按本轮要求统一为黑白灰及四类形状；不照搬参考图中的彩色分区、圆柱或椭圆，也不引入其早期方法主张。

## 固定图形语义

| 图形或线型 | 含义 | 使用约定 |
|---|---|---|
| 浅灰圆角矩形 | 处理步骤 | 包含工具处理、LLM 调用或人工处理；需要区分时在框内注明执行者。L1/L2 为执行阶段。 |
| 白色矩形 | 模型、结构化数据或制品 | 包括元模型、ICM、约束、配置、候选模型、实现代码等；不隐含某种数据库或文件结构。 |
| 白色折角文件形 | 文档、输入或报告 | 包括需求文本、规范片段和文字记录。 |
| 白色菱形 | 判断 | 框内给出条件，控制出边注明“是／否”或具体分支条件。 |
| 实线开放箭头 | 数据流 | 从数据提供者指向接收者；表示输入、生成结果、配置或修订内容的传递。 |
| 虚线开放箭头 | 控制流 | 表示调用、执行分支、继续、重试或终止。 |
| 无箭头实线 | 信息关联 | 用于图3与图6；必须明确标出关系名称，不表示执行顺序、继承或数据传递。 |

背景为纯白；处理框填充 `#E6E6E6`，文字 `#111111`，业务边框与连线 `#333333`。线型而非颜色区分数据流和控制流；所有箭头采用相同开放箭头头型。分图及图例分隔线为浅灰细线，没有业务语义。转折采用正交连线，文字不使用白块遮盖连线。

## 文件与对应图注

每张图均提供可编辑 SVG 与 4800 像素宽 PNG。PDF 合辑为六页：统一图例及图1至图5，使用矢量线条并嵌入中文字体。SVG 保留文本，打开时需要相应中文字体；PDF 可用于不依赖本机字体的核对。

| 文件前缀 | 内容 |
|---|---|
| Fig0_symbol_legend | 四类形状与三类连线的统一说明 |
| Fig1_method_overview | ATLAS 方法总览 |
| Fig2_icm_construction | ICM 构建 |
| Fig3_icm_information_model | ICM 信息对象及其关联 |
| Fig4_task_binding_generation | 任务约束与受约束解码 |
| Fig5_validation_repair | 生成后验证、修复与复验 |

**图1图注。** ATLAS 的领域准备与单次任务执行。领域准备产生 ICM、生成映射及人工编写或接入的检查器，供任务复用；本次任务绑定分别向 L1 和 L2 提供生成约束及检查配置。验收要求所有必需检查完成且通过。普通模型修复返回构造与验证；需求、规则等发生变化时，应相应更新任务绑定。图中重复出现的 ICM 与领域实现资源表示同一资源在两个分图中的引用。

**图2图注。** 从已有领域元模型及自然语言规范构建 ICM。元模型表示同时提供抽取上下文、元素关联依据和 ICM 的结构信息。人工复核按需修订约束含义及元素关联。图中省略记录级来源与状态字段；关联成功不等于约束语义已获确认，相关信息仍需保留。

**图3图注。** ICM 所需信息及其关联的逻辑视图，不限定具体存储字段或实现形式。约束记录与元模型元素分别关联其来源；约束的三类用途可以重叠。检查实现关联信息描述已有工具或人工编写的实现及其覆盖范围，不表示由 LLM 自动生成验证器。

**图4图注。** 本次任务的约束选择、对象和值绑定，以及后端编译和受约束解码。图中数据记录均不意味着自动写回持久化 ICM。编译和词元筛选受后端及分词器实际支持范围限制。解码分图表示正常迭代路径；空候选且不能合法结束、后端异常或预算截断直接记录为失败或未完成。接收完整输出要求满足完整语法和后端结束协议，不意味着所有语义检查均已通过。每次循环使用更新后的匹配状态和当前 LLM 得分。

**图5图注。** L2 检查结果驱动的验收、修复与复验。检查失败和覆盖缺口可能同时存在，按问题分别处理，任何未通过事项均阻止验收。修复受允许操作和尝试上限限制；拒绝不合规修改时保留失败状态。应用修改后重建模型或制品并返回 L2。人工补全信息后重新检查；需求、规则或模型变化时，更新相应任务绑定或制品并复验。图示不新增“全部检查完成后才能修复”的执行策略。

## 重绘尺寸
