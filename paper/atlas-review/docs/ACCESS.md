# Access and branch navigation

| Repository entry | Contents |
| --- | --- |
| [ATLAS branch](https://github.com/Abandooon/AI_XmlGenerator/tree/ATLAS) | Experiment code, data and verification documentation at the branch root |
| [api_rag experiment export](https://github.com/Abandooon/AI_XmlGenerator/tree/api_rag/paper/atlas-review) | Identical experiment tree under `paper/atlas-review/` |
| [Download the ATLAS source ZIP](https://github.com/Abandooon/AI_XmlGenerator/archive/refs/heads/ATLAS.zip) | Complete release with the same relative paths; no GitHub account required |


A GitHub archive contains a single enclosing directory. Enter that directory before using the root commands. Keep all experiment archives, manifests and the four Terra archive parts together. Newly generated outputs must be placed outside the release tree. The commands do not access model APIs.

The [requirement source guide](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/AUTOSAR_REQUIREMENT_PROVENANCE_AND_DESIGN.md) identifies the current 20 AUTOSAR cases and their provenance. The [domain evidence index](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/REVIEWER_EVIDENCE_MAP.md) links inputs, implementations and outputs. [Experiment data](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/EXPERIMENT_DATA.md) gives metrics and their source selectors.

The public export contains experiment materials. Manuscripts, decision letters and author responses are kept outside it. Two experiment archives were repackaged to remove those documents and their document builders; retained experiment members preserve their original bytes. [Archive selection](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/ARCHIVE_SELECTION.json) records exclusions, original identities and current archive hashes. A historical whole-archive hash must not be used as the hash of the repackaged file.
