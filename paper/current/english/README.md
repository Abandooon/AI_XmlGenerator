# English manuscript for SoSyM

[The compiled paper](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/current/english/main.pdf) includes the main text, Appendices A–D and references. Citation numbers use ordinary black text. [The location index](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/current/english/LOCATIONS.md) provides source-line and PDF-page links.

For Overleaf, upload `main.tex`, `references.bib`, `sn-jnl.cls`, both supplied `.bst` files and the eight `Fig*.pdf` files from [this repository directory](https://github.com/Abandooon/AI_XmlGenerator/tree/ATLAS/paper/current/english). Set `main.tex` as the main document and choose XeLaTeX. No author-local files are required. The optional [Overleaf ZIP](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/paper/current/english/SoSyM_English_Integrated.zip) contains exactly these submission inputs.

For a tested local build, use the manuscript-build entry in [the command list](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/COMMANDS.md). It invokes Tectonic and writes all build products to an external directory. [The audit](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/validation/publication_review/COMMAND_AUDIT.md) records the actual compiler result. XeLaTeX on Overleaf is a template configuration; the locally executed command is explicitly identified as Tectonic.

The Springer Nature class and numerical bibliography styles accompany the source. The original reference keys and the eight English figure PDFs were preserved. [The data crosscheck](https://github.com/Abandooon/AI_XmlGenerator/blob/ATLAS/docs/PAPER_DATA_CROSSCHECK.md) connects the manuscript numbers to repository evidence.
